# LeetCode Solutions

A collection of **LeetCode problem solutions written in C#** for practicing algorithms, data structures, and problem-solving.

Current solutions include problems such as:
- Two Sum
- Add Two Numbers
- Longest Substring Without Repeating Characters
- Roman to Integer
- Valid Palindrome

## Built With
- C# / .NET

Solutions are organized inside the `Solutions` folder and can be run through the included C# project.
